# 后端历史文档归档区

本目录用于收纳 [`im-backend`](im-backend) 下不再作为当前有效入口的历史文档、阶段总结和讨论文档。

## 归档范围

应迁入本目录的文档类型：
- 功能总结
- 测试报告
- 版本性快速开始文档
- 架构讨论稿
- 已被主文档或索引文档吸收的专题说明
